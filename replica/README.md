# Paris timelapse replica (Blender)

Procedural recreation of the reference video `reference/PARIS-original-IFhKB5zHWFg.mp4`
("PARIS – 3D TIMELAPSE – 300 BCE to 2025", 180 s, 2560x1440, 30 fps): an oblique
low-poly map of Paris growing era by era, with the era label bottom-left and the year
counter bottom-right.

Everything is generated by scripts; the only external inputs are OpenStreetMap geometry
(river, streets, parks, rail, Paris boundary) and a few landmark GLB models reused from
the old project (Notre-Dame, Eiffel tower, Louvre, Arc de Triomphe, Sainte-Chapelle,
Saint-Germain-des-Prés, Tour du Temple, Petit Pont, Gare du Nord, Palais Garnier).
All ordinary houses are procedural (`scripts/kits.py`).

## Selected version

Video replica from `worktree-video-replica` (`88ccaed`). Imported landmark GLBs are bundled in `assets/models/`.

## Pipeline

Run these commands from `replica/`.

```
python scripts/fetch_osm.py            # Overpass -> data/osm_raw.json   (network)
python scripts/build_geo.py            # -> data/geo.json (metres, origin Notre-Dame)
blender -b --python scripts/preview_kits.py -- kits.png   # exports data/kit_footprints.json
python scripts/growth.py               # city growth engine -> cache/scene_data.npz, rasters.npz
blender -b --python scripts/build_scene.py -- --out cache/paris_replica.blend [--subsample N]
blender -b cache/paris_replica.blend --python scripts/render.py -- --out renders/final [--step 30] [--res WxH]
blender -b cache/paris_replica.blend --python scripts/render_blueprint.py -- --out renders/final/blueprint.png
python scripts/overlay.py --frames renders/final --out renders/paris_replica.mp4
```

`python scripts/compare.py renders/final out.png 10,22,46,61,85,111,141,166` builds a
side-by-side sheet against the reference video for QA.

## Final render on the cluster (minerva, L4 GPUs)

```
blender -b cache/paris_replica.blend --python scripts/pack_blend.py -- --out cache/paris_replica_packed.blend
python scripts/make_masks.py server/masks_2560x1440 2560 1440
# one-time: bash server/setup_runtime.sh on minerva (Blender 4.5.10 + static ffmpeg)
# run dir: /data/users/zhichaoz/blender-render/runs/<run>/{input,scripts,cache,fonts,frames,syslibs,...}
#   input/paris_replica_packed.blend, scripts/{overlay,timeline,render_blueprint,make_masks}.py,
#   cache/{scene_meta.json,scene_data.npz}, fonts/bahnschrift.ttf, frames/mask_*.png, syslibs/libXi.so.6*
export PARIS_RUN_DIR=... WORKERS_PER_GPU=5 ARRAY_TASKS=8
jid=$(sbatch --parsable --export=ALL render_array.sbatch)
sbatch --export=ALL --dependency=afterany:$jid post.sbatch      # blueprint still + ffmpeg post -> output/*.mp4
```

Measured: ~23 s per 2560x1440 frame per worker (Geometry Nodes evaluation dominates), so
8 L4 tasks x 5 workers finish the 5400 frames in about an hour.

## How it works

* `timeline.py` – year(t) curve sampled from the reference every 2 s, era labels, sprout timing.
* `history.py` – hand-authored historical geography: growth rings (Celtic oppidum, Roman
  Lutetia, Frankish nuclei, Philippe-Auguste / Charles V / Louis XIII / Fermiers-généraux /
  Thiers walls, inner and outer suburbs), village nuclei, high-rise estates, La Défense,
  city walls, park and bridge dates, ~75 landmarks with birth/death years.
* `growth.py` – rasterises the rings into a birth-year field (10 m cells), places buildings
  along both sides of every street with an era-dependent spacing, assigns each building a
  kit, a replacement chain (medieval -> classical -> haussmann -> modern) and a sprout
  duration; scatters trees that die when the city arrives; builds road / rail / wall pieces
  with birth years; bakes shader rasters (shore band, park years, water depth) and a relief
  heightmap. Buildings are drawn ~2x real size like the reference film.
* `kits.py` – low-poly building kits per era (celtic, roman, medieval, classical, haussmann,
  modern, suburb, slab) and trees.
* `landmarks.py` – procedural monuments (forum, arena, castles, Invalides, Panthéon,
  Versailles, stations, Sacré-Cœur, towers...) and GLB loader with flat materials.
* `build_scene.py` – Blender scene: terrain grid + baked textures, water meshes, road/rail/
  wall meshes, one point cloud per era instanced through Geometry Nodes (`CityGrowth`
  deletes points outside [birth, death) and animates a pop-in scale), keyframed Year on
  every modifier, landmark holders animated per year, camera pull-back looking north-east,
  sun/world, mist haze compositor.
* `overlay.py` – ffmpeg post: tilt-shift blur, vignette, ASS subtitles (Bahnschrift) for
  era + year, wipe to the outro blueprint still, fades, H.264 encode.
